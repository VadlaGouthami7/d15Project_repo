## 🚀 FastAPI CRUD API with MySQL

A beginner-friendly REST API project built using **FastAPI**, **MySQL**, **SQLAlchemy**, and **Pydantic**. This project demonstrates how to connect FastAPI with a MySQL database and perform CRUD (Create, Read, Update, Delete) operations.

## 📁 Project Structure

```
fastapi_db/
│
├── main.py        
├── database.py        
├── model.py  
├── schemas.py         
├── crud.py            
├── requirements.txt 
└── README.md
```
main.py 
 -> for the logic and entry point for the app

schemas.py
 -> to define the structure of data from user

database.py
-> for defining the connection with mysql_database

models.py 
-> to define the structure of tables in the database

crud.py
-> to perform crud operations on the data

### 📌 Project Overview

This project was developed as part of my backend development learning journey. It demonstrates how to build REST APIs, connect them to a MySQL database, validate incoming data using Pydantic, and perform database operations using SQLAlchemy ORM.
